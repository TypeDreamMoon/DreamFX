## DFX3045

**Historical diagnostic.** This code is no longer emitted by the current source tree. The section
is retained so older diagnostic links remain usable; it is not part of the generated active-code list.

The earlier error was:

```text
'%s' is not a type a particle attribute can have.
```

It described a particle-attribute declaration in a `.dfm` body using a type that was not a Niagara
value type. The historical fix was to use a supported DSL value type such as `float`, `int`,
`bool`, `Vector2`, `Vector`, `Vector4`, `Color`, `Position` or `Quat`. For current authoring rules,
see [modules and dynamic inputs](../../language/dfm.md) and [values and types](../../language/values.md).
